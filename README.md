## Features
- Add Task
 Task Title – the name of the task.
 Due Date – the deadline for completion.
 Details/Description – additional notes, instructions, or relevant links.
 Create Task Button – saves the task and displays it in the Active Tasks list.

- View Tasks
  Displays all created tasks in the Active Tasks section.
  Shows task information such as title, description, due date, and status.
  Helps users monitor their pending and completed work.

- Edit Task
  Allows users to modify existing task information.
  Users can update the title, due date, or description.
  Useful for correcting or changing task details.
  
- Delete Task
  Removes a task from the system.
  Helps users clear completed, canceled, or unnecessary tasks.
  Prevents outdated tasks from cluttering the workspace.

- Update Status
  Allows users to mark tasks as Completed or revert them to Pending/Active.
  Updates the completion counter (e.g., "0/0 Completed").
  Helps track progress and productivity.
