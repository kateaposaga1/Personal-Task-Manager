## Features
- Add Task - Create a new task with a title, due date, and description.
- View Tasks - Display all active and completed tasks.
- Edit Task - Update task details such as title, date, or description.
- Delete Task - Remove unwanted or completed tasks.
- Update Status - Mark tasks as completed or pending.
